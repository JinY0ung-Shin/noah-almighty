# Converter fonts (vendored, unmodified, SIL OFL 1.1)

Every file here is byte-identical to its upstream release (no subsetting, renaming of internal names, or
instancing), so the OFL's Reserved Font Name clause is not triggered; the OFL allows embedding in documents.
Only the four Pretendard files are ever embedded into a .pptx (profile `embedded`). The others exist so the HTML
can be measured the way PowerPoint will lay it out.

## Generated files — never hand-edit

`fonts.json` and the two stylesheets `../theme/fonts-embedded.css` / `../theme/fonts-malgun.css` are GENERATED by
the PoC's font generator (`scratch/fonts/gen_fonts.py`, preserved for maintainers under
`docs/pptx-converter/maint/`) together with its validators. The weight ranges in the CSS reproduce the builder's face
resolution (nearest `cssWeight`, tie → heavier) for every weight 1..1000, the malgun faces carry per-range
`size-adjust` and line-metric overrides measured against the real Malgun Gothic, and every path inside
`fonts.json` is relative to the converter directory. Edit the generator, regenerate, then re-run the self-test
(`deck.sh selftest`) and refresh the golden IR only after a PowerPoint spot-check (converter `README.md`).

The internal CSS family `PoC Malgun Substitute` keeps its PoC name on purpose: it never reaches a .pptx (the builder
writes 맑은 고딕, and the `font-coverage` gate fails a deck that names the substitute).

Server images register Pretendard, Gothic A1 and Selawik with fontconfig (never `NotoSansKR-VF.ttf`: LibreOffice
renders its Thin instance) so LibreOffice previews of edited decks use these faces.
